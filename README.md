# BC Integration Starter documentation

Documentation website for [`@nobertdev/bc-intergration-starter`](https://www.npmjs.com/package/@nobertdev/bc-intergration-starter).

## Local development

```sh
npm install
npm run dev
```

## Validation

```sh
npm run lint
npm run build
```

The production files are written to `dist/`.

## Package source

The CLI source is maintained in the [`bc-intergration-starter`](https://github.com/NOBERT167/bc-intergration-starter) repository.
